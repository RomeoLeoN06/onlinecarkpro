# 🎡 Çarkıfelek PRO - Stüdyo Kalitesinde Online Şans ve Karar Çarkı

Modern web teknolojileri ile geliştirilmiş; ultra-lüks tasarıma, gerçekçi fizik motoruna ve zengin ses efektlerine sahip profesyonel online çark uygulaması.

---

## ✨ Özellikler

- 🎡 **Gerçekçi HTML5 Canvas & Fizik Motoru**:
  - Yüksek DPI (Retina / 4K) kristal netliğinde çizim.
  - Yaylanma fiziğine (Spring Damper) sahip dinamik ibre.
  - Çark çevresinde senkronize parıldayan animasyonlu LED ışıklar.
  - **Arka Planda Dinamik Dönüş (Idle Drift)**: Çarka basılmadığında bile şansı sürekli değiştiren hafif ve akıcı arka plan salınımı.
  - Kriptografik güvenli rastgelelik (`crypto.getRandomValues`) ve ağırlıklı olasılık dağılımı.
- 🎨 **6 Özelleştirilebilir Lüks Tema**:
  - ⚡ **Cyberpunk Neon**: Elektrik mavisi, parlak neon pembe ve fütüristik parıltılar.
  - 👑 **Royal Casino / Altın Lüks**: Derin zümrüt ve 24 ayar altın yansımaları.
  - 🌌 **Cosmic Deep Space**: Nebula moru ve galaktik ışıklar.
  - 🍭 **Pastel Rüya**: Instagram / Soft aesthetic tatlı tonlar.
  - 🌅 **Sunset Synthwave**: 80'ler retro neon dalgası.
  - ⚡ **Titanyum / Stealth**: Minimalist mat grafit ve karbon şıklığı.
- 🔊 **Prosedürel Web Audio API Ses Motoru**:
  - Hıza göre frekansı ve tonu değişen mekanik çivi tıkırtıları.
  - Hızlı çevirme rüzgar efekti (whoosh).
  - Kazanan çıktığında zafer fanfarı ve çan sesleri (0 harici bağımlılık, %100 kesintisiz).
- 🏆 **Kutlama & Kazanan Modalı**:
  - Temaya özel konfeti ve parçacık patlaması.
  - Sonucu panoya kopyalama, çarktan eleme veya anında tekrar çevirme.
- 📱 **Mobil & Dokunmatik Uyum**:
  - Dokunarak / fırlatarak çark çevirme desteği.
  - Tüm telefon ve tabletlerde kusursuz responsivite.
- 📋 **Akıllı Seçenek & Liste Yönetimi**:
  - Her seçenek için özel renk ve ağırlık (şans oranı) belirleme.
  - Çok satırlı metinleri tek tıkla çarka ekleyen **Toplu Ekle** penceresi.
  - Rastgele karıştırma (Shuffle) ve alfabetik sıralama.
- 🍿 **Yayıncı & Sinematik Modu**: Twitch, YouTube ve sunumlar için tüm panelleri gizleyen tam ekran çark modu.

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Canlı dağıtım için derleyin
npm run build
```

## 🛠️ Kullanılan Teknolojiler

- **HTML5 Canvas** (Retina scaling & Custom Physics)
- **CSS3 / Vanilla CSS** (Glassmorphism, CSS Custom Properties / Theming)
- **Modern JavaScript (ES6+ Modules)**
- **Web Audio API** (Sentezlenmiş prosedürel ses efektleri)
- **Vite** (Geliştirme ve derleme aracı)
